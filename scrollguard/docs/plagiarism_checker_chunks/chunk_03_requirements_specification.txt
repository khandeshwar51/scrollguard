6.2. Software Requirements & Production Package Manifest

The software stack relies exclusively on verified open-source dependencies and standard W3C browser specifications:

Zero-Install Client Architecture: The client extension requires zero third-party drivers or native OS binaries. All components execute within Chromium

Deterministic Dependency Locking: All core npm packages are strictly locked to exact semantic versions in package-lock.json , preventing unintended API breaks or upstream supply-chain vulnerabilities during deployment.

Detailed Input, Processing & Verification Specification

System shall inject lightweight content scripts into YouTube Shorts, Instagram Reels, Facebook Reels, TikTok, and X feeds within 100ms of page load.

System shall monitor window.location.pathname. On standard homepages (youtube.com/, instagram.com/), the widget shall unmount and remain hidden.

System shall track video visibility using IntersectionObserver. Only videos intersecting >= 60% of viewport with paused==false shall increment counters.

System shall render a draggable Shadow DOM badge displaying live clip counts and Avatar emotion (Happy for =100%).

When totalVideosWatched >= videoLimit, system shall immediately trigger Stage 1 (Soft Nudge Modal), halting momentum and auto-pausing media.

If user overrides limits, system shall transition sequentially: Stage 2 Intention Entry (+5 clips), Stage 3 Breathing (+8 clips), Stage 4 Break (+11 clips).

During active modal states, system shall intercept wheel, touchmove, and keyboard keys (Down, Up, Space, j, k) using capture: true.

System shall finalize and flush sessions to IndexedDB after 90 seconds of inactivity. Daily counters shall reset upon detecting midnight rollover.

6.3. Functional Requirements Specification (Part 1: Ingestion & Telemetry)

The functional capabilities of ScrollGuard are enumerated below. Part 1 defines data ingestion, active viewport detection, and real-time state interception:

Verification Contract: Requirements FR-01 through FR-08 are unit-tested with Vitest fixtures simulating DOM mutations, route changes, timer expirations, and boundary watch sessions to verify 100% deterministic execution.

Architectural Workflow for FR-01 through FR-04: When a user navigates to a short-form video endpoint, the content script evaluates the route, creates an open Shadow Root, and mounts the React root. As videos enter the center of the screen, IntersectionObserver triggers VideoTracker.track() , establishing a 1-second active playback heartbeat.

In-Memory Cache Validation (FR-05 & FR-08): Daily limits and clip aggregates cached in chrome.storage.local are verified across browser tabs. Inactivity timers evaluate Date.now() - lastActivity > 90000 to flush completed sessions atomically into browser IndexedDB.

6.3. Functional Requirements Specification (Part 2: Escalation & Analytics)

Part 2 defines progressive friction escalation, mathematical scoring formulations, and analytics cockpit capabilities:

Predictive Integrity Guarantee: Requirement FR-15 mandates that doomscroll confidence calculations are based strictly on client-side telemetry invariants without heuristic guessing or probabilistic black-box assumptions.

Automatic state recovery from chrome.storage.local if background service worker is suspended during idle periods.

Total memory consumption bounded < 35 MB across 10 active tabs; automatic 90s session finalization prevents leaks.

Dark glassmorphic aesthetic with high-contrast typography, color-coded Brain Avatar emotion badges, and smooth CSS easing.

Identical execution behavior across Google Chrome, Brave, MS Edge on Windows 10/11, macOS, and Linux.

100% test pass rate maintained across all 21 Vitest specification assertions covering dopamine math and state transitions.

Whitelisted regex character matching on user text inputs to prevent XSS attacks at the Shadow DOM boundary.

Achieve 99.9% uptime across active browsing sessions, resilient against host SPA route mutations and tab recycling.
